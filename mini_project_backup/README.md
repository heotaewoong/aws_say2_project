# 🧬 Rare-Link AI: 멀티모달 희귀 폐 질환 진단 시스템

이 프로젝트는 **"환자의 흉부 엑스레이(이미지)와 의사 소견서(텍스트)를 함께 분석해서 희귀 폐 질환을 진단하는 인공지능(AI) 웹 서비스"**의 미니 버전입니다.

초보자분들도 이해하기 쉽게 본 프로젝트가 어떤 역할을 하는지, 그리고 각 파일들이 무슨 일을 하는지 안내해 드립니다!

---

## 🏥 프로젝트 전체 요약: "AI 보조 의사 시스템"
환자가 병원에 방문하면 의사가 진찰 소견서(글)를 작성하고 엑스레이(사진)를 촬영합니다. 
이 시스템은 이 두 가지 데이터를 받아들여 인공지능이 **"이 환자는 어떤 희귀 질환에 걸렸을 확률이 가장 높은지"** 분석하고, 병의 단서와 최종 결과 레포트(보고서)까지 정리해서 알려줍니다.

## ⚙️ 프로그램 작동 순서
1. **입력:** 환자의 텍스트 소견서와 엑스레이 시각 이미지를 프로그램에 넣습니다. (`app.py`를 실행하여 띄운 웹 화면에서 진행)
2. **단서 분석 및 추출:** 
   - 글에서는 어떤 증상이 있는지 핵심 단어를 찾습니다.
   - 엑스레이 사진에서는 병변(이상이 있는 아픈 부위)을 찾아냅니다. 
3. **추리 및 진단:** 위에서 발견된 단서(증상)들을 하나로 합쳐서 질환 백과사전과 비교한 뒤, 가장 의심되는 희귀 질환 순위를 도출합니다.
4. **최종 결과 도출:** 화면에 엑스레이 상의 이상 부위를 표시(시각화)해주고, 예상 질병 리스트와 최종 의사용 보고서를 완성하여 보여줍니다.

---

## 📁 폴더 내 주요 파일들의 역할 (AI 직원들)

각 파이썬(`.py`) 파일들은 이 가상 병원 시스템에서 특정한 역할을 맡은 AI 담당자들이라고 생각하시면 이해가 쉽습니다.

* **💻 `app.py` (접수처 직원 및 웹 화면 대시보드)**
  * 사용자가 인터넷 창에서 직접 환자의 기록을 타이핑하고 사진을 업로드할 수 있게 해주는 **웹 앱 화면**을 만들어 줍니다. (Streamlit이라는 파이썬 도구를 사용했습니다.)

* **🛠️ `main.py` (메인 조종실 / 테스트 공간)**
  * 웹 화면(UI)을 통하지 않고 파이썬 코드만으로, 이미 저장된 테스트 환자의 데이터를 넣어 전체 진단 기계가 잘 돌아가는지 테스트해 보는 실행 파일입니다.

* **📝 `extractor.py` (텍스트 해독 전문가)**
  * 의사가 쓴 복잡한 영어 소견서를 읽고, 핵심 증상(예: 호흡 곤란, 곤봉지 등)만 데이터로 추출해 내는 역할을 합니다. (구글의 Gemini AI 모델을 사용해서 글을 이해합니다.)

* **👀 `vision_engine.py` (엑스레이 분석 전문가)**
  * 흉부 엑스레이 사진을 분석하여 어느 부위에 이상이 있는지 병변을 찾아내는 시각 AI 엔진입니다. 사진에 비정상적인 부위를 붉은색으로 칠해서 보여주는 시각화 기술(Grad-CAM)도 담당합니다.

* **🕵️‍♂️ `inference_engine.py` (명탐정 및 진단 전문가)**
  * 글씨 해독 전문가(`extractor.py`)와 시각 분석 전문가(`vision_engine.py`)가 각자 찾아낸 증상 단서들을 모두 취합합니다. 그리고 방대한 의학 지식을 바탕으로 가장 확률이 높은 희귀병의 순위를 수학적으로 도출합니다.

* **🖨️ `reporter.py` (보고서 작성 담당자)**
  * 모든 진단 과정이 끝나면, 의사 선생님이 종합적인 결과를 한눈에 파악하기 편리하도록 최종 텍스트 진단 요약 리포트를 깔끔하게 자동 작성해 줍니다.

* **📚 `knowledge_base.py` & `en_product4.xml` (의학 백과사전)**
  * 수많은 희귀 질환의 이름과 각 병의 특징적 증상들이 데이터베이스로 정리되어 있는 의학 사전입니다. AI 진단 전문가가 이 사전을 참고하여 결론을 내립니다.

* **🧪 `data_test.py` (실전 데이터 연결 테스트)**
  * 실제 환자 CSV 데이터 파일(`discharge.csv`, `labevents.csv` 등)을 불러와서 특정 환자의 진료 텍스트와 혈액검사 수치를 AI로 분석하는 테스트 스크립트입니다. 결과로 해당 환자의 HPO 코드(질병 특성 코드) 목록을 출력합니다.

* **🔬 `test.py` (빠른 단위 테스트)**
  * 프로젝트의 개별 기능들이 기본적으로 잘 작동하는지 간단하게 확인하는 가장 짧은 테스트 파일입니다. 새로운 기능을 추가한 후 "일단 돌아가나?" 체크할 때 사용합니다.

* **🎥 `test_cam.py` (Grad-CAM 시각화 테스트)**
  * 엑스레이 사진에서 AI가 이상 부위를 찾아 붉은색 열지도(Heatmap)로 표시해주는 Grad-CAM 기능만 따로 테스트하는 파일입니다. 이 파일을 실행하면 아래의 `cam_output.png`가 결과물로 생성됩니다.

* **🔭 `test_vision.py` (시각 엔진 단독 테스트)**
  * `vision_engine.py`의 엑스레이 분석 기능을 전체 시스템과 연결하지 않고 단독으로 테스트하는 파일입니다. 엑스레이 분석 부분에만 문제가 생겼을 때 원인을 빠르게 찾기 위해 사용합니다.

* **🖼️ `cam_output.png` / `temp_cxr.jpg` / `person3_bacteria_13.jpeg` (이미지 파일들)**
  * `cam_output.png`: `test_cam.py`를 실행했을 때 생성되는 **결과 이미지**입니다. 엑스레이 위에 AI가 주목한 부위가 색으로 표시되어 있습니다.
  * `person3_bacteria_13.jpeg` / `temp_cxr.jpg`: 테스트에 사용되는 **샘플 엑스레이 사진**입니다.
